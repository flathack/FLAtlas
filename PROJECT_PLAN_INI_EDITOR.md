## INI Editor Anpassungen

mach mir für den ini editor einen plan um folgende features umzusetzen: 

- [x] einfache struktur der buttons, mehr wie ein Text Editor aufgebaut. 
- [x] Datei Speichern oben rechts in grün
- [x] Änderungen verwerfen daneben in rot
- [x] ich will einen änderungsverlauf pro Zeile haben (so wie GIT) und ich will sehen, wann eine Zeile zuletzt geändert wurde und will auch änderungen langfristig rückgängig machen können. Die Info dafür soll im Mod gespeichert werden, so dass die Änderungen an den Mod Ordner gebunden sind.
- [x] wenn ich eine Datei bearbeite, sollen veränderte Zeilen farblich markiert werden, so dass man sieht was man geändert hat.
- [x] ich will eine Suchfunktion innerhalb der Datei haben
- [x] Suchen und Ersetzen function
- [x] Suchfunktion dateiübergreifend, nach Dateinamen oder inhalten
- [x] Log Dateien wie INI datein behandeln
- [x] Wenn Ordner angeklickt werden, kann ich die Dateien darin sehen und kopieren / verschieben wie bei einem normalen explorer. Baue mir erstmal die wichtigsten Features für einen Explorer ein. Mehrere Dateien markieren etc.
- [x] Rechtsklick auf eine Zeile die in der history steht und dann "Historie" zeigt mir in einem separaten Fenster die historie nur für diese Zeile an. z. b. 
"[2025-03-30--15:00] Zeileninhalt XYZ"
"[2025-03-30--14:00] Zeileninhalt XYZ"
"[2025-03-29--12:00] Zeileninhalt XYZ"
- [x] im tree soll pro datei angzeiegt werden, wann diese zuletzt bearbeitet worden ist.
- [x] Editor Eigene Tabs unterhalb der Hauptnavigation
- [x] Umbenennung: INI Editor zu -> File Explorer
- [x] einbau von Standard Notepad befehlen incl. Iconbar siehe screenshot
