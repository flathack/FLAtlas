# FLAtlas Python (Legacy)

This public repository is now kept as the download and release archive for the
legacy Python version of FLAtlas.

The active source development has moved away from this public GitHub repository.
If you are looking for the old Python builds, use the release downloads:

- [Download FLAtlas Python releases](https://github.com/flathack/FLAtlas/releases)

## Recommended Version

For new installs and ongoing Freelancer modding work, please use **FLAtlas V2**.
It is the newer and improved FLAtlas version and is the recommended project for
future development:

- [FLAtlas V2 on GitHub](https://github.com/flathack/FLAtlas-V2)

## Which Version Should I Use?

- Use **FLAtlas V2** if you are starting fresh or want the best current FLAtlas
  experience.
- Use **FLAtlas Python legacy releases** only if you specifically need the older
  Python-based toolchain or a previous V1 workflow.

## Support Notes

The Python version remains available through GitHub Releases, but new feature
work should target FLAtlas V2.
